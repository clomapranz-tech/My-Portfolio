**Central Purchasing Unit**

What is a Central Purchasing Unit? 
- A central purchasing unit is a centralized team or department within an organization,
  responsible for all procurement activities, a single office/unit is responsible managing purchases.
  **This was Created by 4 Students including me for a Thesis Project**

**Who uses it?**

**User (Requester)**: files a purchase request and tracks status.
**Department/Unit Head & VP Admin**: review and approve/reject.
**Finance**: checks budget/compliance and approves.
**CPU (Admin/Super Admin)**: final review, completes purchase; also manages users/colleges.
Dashboards and permissions are enforced via role-based access. 
 

**Step-by-step process flow (end-to-end)**

User logs in and submits a request (items, qty, justification, docs). 

Dept Head validates necessity; may return for correction or approve. 

VP Admin prioritizes vs. institutional goals; rejects with feedback or approves. 

Finance checks budget/policy; rejects (back to user) or approves. 

CPU Admin/Super Admin do final verification (vendors, docs, compliance) and complete/finalize the request. 

Throughout, the system logs approvals/signatures, keeps attachments, and updates status for the requester. 

This structured workflow reduced delays, errors, and manual follow-ups while improving traceability.
